**Date Filed**: November 16, 2023

**Status**: Substantive Examination (July 16, 2024)

## Abstract

This patent presents an active defense system for link flooding attacks based on network topology obfuscation, addressing critical security challenges in software-defined networking environments.

## Technical Field

Network security, software-defined networking (SDN), DDoS defense, link flooding attacks

## Key Features

- Network topology obfuscation mechanism
- Active defense against link flooding attacks
- Software-defined networking based implementation
- Real-time attack detection and mitigation
